Anatomy

17 animated diagrams of how a machine actually behaves, built by hand rather than generated. Each one isolates a single idea and shows it moving, because most of these are far easier to watch than to read about.

They are pure SVG with CSS keyframes. No JavaScript, no library, no network request, and they animate the same way in a blog post, a slide deck or a README.

Press copy embed on any diagram to take it with you.

Use them. These are free to embed, reuse and adapt in posts, talks, courses and documentation, commercial or not. The only thing asked in return is a link back to r00tlv.me somewhere near the diagram. If you are teaching with them and want a variation that is not here, that is a reasonable thing to ask for.
